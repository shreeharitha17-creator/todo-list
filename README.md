# ✅ To-Do List Web Application

## 📌 About the Project
This is a simple and user-friendly To-Do List web application
developed as part of my CodeOrbit Full Stack Development Internship.

It helps users organize their daily tasks and manage their work.

## ✨ Features
- Add new tasks
- View your task list
- Mark tasks as completed
- Delete tasks
- Simple and user-friendly interface
- Responsive design

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 🚀 How to Run
1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

## 📂 Project Structure
- `index.html` - Website structure
- `style.css` - Website styling
- `script.js` - Task management functionality
